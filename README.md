# Luiz Gustavo de Campos

Desenvolvo ferramentas internas para operações de energia solar. Meu trabalho vai do levantamento de requisitos ao desenvolvimento, e também atuo na elaboração de projetos fotovoltaicos.

Sou formado em Análise e Desenvolvimento de Sistemas. Em BI, tenho experiência com consultas SQL no SAP HANA, modelagem de dados e criação de painéis em Power BI.

## Projetos

**[Dashboard de controle de cargas](https://github.com/Luiz-campos3/GitHub-projetosBI)**  
Painel em Power BI para acompanhar notas fiscais, devoluções, status de cargas e prazos de entrega. O README documenta medidas DAX e filtros por período, filial e rota.

## Tecnologias

- **Desenvolvimento:** React Native, Expo, TypeScript e integração com APIs
- **Dados e BI:** Power BI, DAX, Power Query, SQL e SAP HANA
